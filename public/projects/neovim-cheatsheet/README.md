# Neovim cheatsheet

Open `index.html`. Offline, light-only, no install or build.

Hosted with the blog at `/projects/neovim-cheatsheet/`. Edit the files here, run `npm run build` and `npm run preview` from the repository root, then open `http://localhost:4321/projects/neovim-cheatsheet/`. Pushing to `main` publishes it through the existing GitHub Pages workflow.

Everyday keys on one laptop screen; **All commands** adds the full index in the same layout. Italics mark inputs. Neovim defaults; Zed may differ.

Plain HTML/CSS/JS, five files:

- `index.html` — page
- `style.css` — layout
- `script.js` — shortcuts, formatting, toggle
- `reference.js` — bundled Neovim index (2026-10-19)

Selection follows [Tutor](https://github.com/neovim/neovim/blob/master/runtime/tutor/en/vim-01-beginner.tutor) and manual chapters [02](https://neovim.io/doc/user/usr_02/), [03](https://neovim.io/doc/user/usr_03/), [04](https://neovim.io/doc/user/usr_04/). Expanded commands: [official index](https://github.com/neovim/neovim/blob/master/runtime/doc/index.txt).
